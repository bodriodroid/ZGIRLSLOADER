Guía de inicio según tu plataforma

Al igual que proyectos de preservación como OpenMW o Ship of Harkinian, ZGirlsLoader es un motor limpio: aportas tus propios archivos legales y el cargador hace el resto.

1

Compila o instala el APK ARM64

Genera app-debug.apk desde android/ con Android NDK 26.1. Cada build sube el versionCode para actualizar encima sin perder tus ajustes.

2

Importa tus datos al Core Vault cifrado

Sin pedir permisos globales de almacenamiento. Selecciona tus carpetas desempaquetadas o descarga tu copia legal vía Steam DepotDownloader (App 245170).

3

Añade escenarios o paletas en mods/ y juega

Usa el D-Pad y los 6 botones táctiles multitáctiles. Ajusta la escala de renderizado (33%–100%) en Developer Options según tu GPU móvil.

REQUISITOS ANDROID (ZGIRLSMOBILE)

  • Dispositivo ARM64-v8a (Android 8.0+ recomendado)
  • Copia legal de Skullgirls 2nd Encore (PC/Steam)
  • Sin acceso Root ni MANAGE_EXTERNAL_STORAGE
  • Controles táctiles simultáneos (caminar + atacar)
  • Soporte nativo para favcolours/ y mods/stages/
1

Clona SDL2 2.30.9 y compila con Ninja

cmake -S . -B build -G Ninja -DZDROID_SDL2_SOURCE_DIR=../SDL && cmake --build build

2

Monta tus carpetas extraídas (VFS insensible a mayúsculas)

Ejecuta ./build/zdroid_viewer /ruta/unpacked. Puedes pasar montajes extra (ui/Win, sprites, stages) como argumentos adicionales.

3

Valida mods y usa las herramientas CLI

Usa zdroid_probe, zdroid_foit y zdroid_duel para depurar personajes, hitboxes y escenarios sin abrir ventana.

REQUISITOS LINUX / STEAM DECK

  • Compilador C++17 (GCC 10+ / Clang 12+), CMake y Ninja
  • SDL2 2.30.9 (enlace fuente directo)
  • Opcional: Python 3 para tests/real_diff.py
  • Opcional: DepotDownloader en PATH para tab Steam
  • Compatible con teclados (WASD + JKL/UIO) y mandos
1

Prepara el entorno C++17 + SDL2

Compila con MSVC, Clang o MSYS2/MinGW usando el mismo CMakeLists.txt portable del repositorio.

2

Usa Home / Browse o Steam (App 245170)

Desde la propia UI puedes explorar tus archivos extraídos o invocar DepotDownloader enviando tus credenciales únicamente por stdin.

3

Edita paletas y depura en vivo

Mantén pulsado un personaje en Char Select (o pulsa C) para abrir el Colour Editor y pulsa F1 en combate para ver hitboxes.

REQUISITOS WINDOWS / MACOS

  • Windows 10/11 (x64) o macOS 12+
  • Soporte OpenGL / SDL2 acelerado por hardware
  • Carpeta zgirls.savini portable (sin modificar registro)
  • Lectura directa de Main.gbs y Charselect.gbs
