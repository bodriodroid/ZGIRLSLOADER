// Instalación Rápida (BYOC — Bring Your Own Copy)

De tu copia legal al combate en 4 pasos

Al igual que motores de preservación como OpenMW o Ship of Harkinian, ZGirlsLoader es código limpio MIT: aportas tus archivos legales extraídos y el cargador los monta sin tocar ni un byte original.

PASO 01 • FUENTE
Tu Copia Legal (App 245170) Carpetas extraídas o descarga oficial con Steam DepotDownloader (stdin-only).
PASO 02 • SEGURIDAD
VFS o Core Vault Cifrado En Android importa vía selector nativo sin permiso global de almacenamiento.
PASO 03 • CAPA MODS
mods/ + favcolours/ Agrega paletas, voces JP o stages como Anna Killer sin mutar la base.
PASO 04 • RUNTIME
PC / Steam Deck / Android Ejecuta zdroid_viewer o el APK ARM64 con 60 FPS y overlay F1.
1

Compila o instala el APK ARM64-v8a

Genera app-debug.apk desde android/ con Android SDK 34 + NDK 26.1.10909125. Cada build sube el versionCode para actualizar encima conservando tus datos.

2

Importa tus datos al Core Vault cifrado

Sin pedir MANAGE_EXTERNAL_STORAGE ni Root. Selecciona tus carpetas desempaquetadas o descarga tu copia legal vía Steam (App 245170).

3

Juega con controles multitáctiles o añade mods

Cruceta + 6 botones en cristal (caminar y atacar a la vez). Ajusta resolución (33%–100%) en Developer Options.

REQUISITOS ANDROID (ZGIRLSMOBILE)

  • Dispositivo ARM64-v8a (Android 8.0+ / SDK 34 build)
  • Archivos desempaquetados de tu copia legal (PC/Steam)
  • Sin Root ni acceso global a todos los archivos
  • Botón Back de Android sale limpiamente del combate
  • Nota: Menú y Lua recientes validados en Linux; APK vía Gradle/CI
1

Clona SDL2 2.30.9 y compila con CMake + Ninja

cmake -S . -B build -G Ninja -DZDROID_SDL2_SOURCE_DIR=../SDL && cmake --build build

2

Monta tus carpetas extraídas (multi-mount)

./build/zdroid_viewer /ruta/unpacked /ruta/ui_Win /ruta/sprites. El VFS indexa por sufijos ignorando mayúsculas.

3

Depura con CLI Tools y Oráculo Python

Usa zdroid_probe, zdroid_foit, zdroid_duel y tests/real_diff.py sin abrir ventana.

REQUISITOS LINUX / STEAM DECK

  • C++17 (GCC 10+ / Clang 12+), CMake y Ninja
  • SDL2 2.30.9 (enlace directo desde fuente)
  • Opcional: Python 3 para tests/real_diff.py
  • Controles: WASD (doble toque dash), JKL / UIO, F1 hitboxes
  • Opcional: DepotDownloader en PATH para tab Steam
1

Compila con el mismo CMakeLists portable

Compatible con MSVC, Clang o MinGW enlazando contra release-2.30.9 de SDL2.

2

Explora desde Home/Browse o Steam (App 245170)

Usa el explorador integrado o descarga tus paquetes pasando usuario y Steam Guard exclusivamente vía stdin.

3

Edita paletas y prueba mods al instante

Mantén pulsado un luchador en Char Select (o pulsa C) para abrir el Colour Editor y guardar en favcolours/.

REQUISITOS WINDOWS / MACOS

  • Windows 10/11 (x64) o macOS 12+ con OpenGL
  • Configuración portable en zgirls.savini (sin registro)
  • Soporte directo para Main.gbs y Charselect.gbs
  • Sobrescritura rápida vía variables ZDROID_DEV_*
